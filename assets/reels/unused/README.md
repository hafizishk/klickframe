# Not currently on the page

Sources kept for reference. `npm run media` only reads the top level of
`assets/reels/`, so nothing in here is processed or shipped.

**puma-future9.mp4** — Puma Future 9 promo with Flair Academy.

Benched on resolution: it is 360x640 where every other reel is 720x1280, so on
a card it would be visibly the softest thing in the work rail. It is also a
second football-boot product film, and `brand.mp4` — Puma Ultimate 9 with
Weston Corp — covers that ground at full resolution while carrying two client
logos rather than one.

Nothing wrong with the piece; it is a resolution and duplication call, and an
easy one to reverse. To use it, move it back to the top level under a slot name
(`brand.mp4`, `corporate.mp4`, …) and re-run `npm run media`.
